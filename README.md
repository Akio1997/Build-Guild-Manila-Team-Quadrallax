## Meet "LEGS"!
Legs is a macropad designed to help you set shortcuts for different programs/softwares - whether it be games or tools.

**Legs is comprised of:**
- 4 Switches, 3 are assigned to keyboard shortcuts for different applications that the user sets. The other is assigned to switching between said keyboard shortcuts (for example, you can switch between having keyboard shortcuts for Davinci Resolve and OSU!.)
- 3 LEDs helping you see which mode/keyboard shortcuts are activated
- A Cover that serves as the macropad's protection when closed, and serves as a small notepad holder when opened.
